# Своя музыка для vedit

Положите сюда треки (mp3/wav/ogg/m4a/flac) — они используются раньше, чем поиск в Openverse.
Настроение подбирается по `library.json` или по слову в имени файла (`chill_morning.mp3` → chill).

```json
[
  { "file": "chill_morning.mp3", "moods": ["chill", "emotional"], "title": "Morning", "artist": "Me", "license": "own", "attribution": "" }
]
```

Настроения: upbeat, chill, dramatic, inspiring, tech, funky, emotional.
Без своих треков музыка ищется в Openverse (CC0 / CC BY, Jamendo и Freesound); для CC BY автор и ссылка
попадают в подпись ролика — их нужно оставлять в описании поста.

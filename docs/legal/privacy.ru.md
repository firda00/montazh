# Политика конфиденциальности (черновик)

> ЧЕРНОВИК для юриста. Не является окончательной редакцией. Дата: 16.10.2026.

**Какие данные мы храним**
- Telegram id, имя и username, язык интерфейса, цель использования (которую вы выбрали), дату регистрации и последнего визита.
- Настройки (формат, стиль, голос, способ отправки), историю задач (тип, статус, время, оценки) и расходы на обработку.
- Загруженные видео, фото и голосовые сообщения, а также готовые ролики — только на время обработки и не дольше 7 дней, затем они удаляются автоматически.

**Зачем**
Чтобы выполнять ваши задачи, считать лимиты и кредиты, отвечать на обращения и улучшать сервис. Мы не продаём данные и не используем ваши видео для рекламы.

**Кому передаются данные (обработчики)**
- **Anthropic (Claude)** — текст задачи, расшифровка речи и описание кадров для плана монтажа, сценариев и переводов.
- **Google (Gemini API, Cloud Text-to-Speech)** — кадры и фрагменты видео для понимания сцен и поиска моментов в играх, текст для озвучки. На бесплатном уровне Gemini API Google может использовать запросы для улучшения своих продуктов.
- **Openverse** — поисковые запросы (ключевые слова) для открытых фото и музыки; ваши файлы туда не отправляются.
- **Telegram** — доставка сообщений и файлов.
- **Google Colab** — только если вы сами загружаете туда задание для аватара.

**Ваши права**
Вы можете попросить администратора удалить ваши данные и аккаунт, отключить новости бота в ⚙️ Настройках и в любой момент перестать пользоваться ботом.

**Безопасность**
Данные хранятся на сервере сервиса; доступ есть только у администраторов. Файлы удаляются автоматически по сроку хранения.

**Изменения**
Политика может обновляться; актуальная версия всегда доступна в боте.

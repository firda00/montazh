# Политика конфиденциальности (черновик)

> ЧЕРНОВИК для юриста. Не является окончательной редакцией. Дата: 19.10.2026 (этап 30).

**Какие данные мы храним**
- Telegram id, имя и username, язык интерфейса, цель использования (которую вы выбрали), дату регистрации и последнего визита.
- Настройки (формат, стиль, голос, способ отправки), историю задач (тип, статус, время, оценки) и расходы на обработку.
- Загруженные видео, фото и голосовые сообщения, а также готовые ролики — только на время обработки и не дольше 7 дней, затем они удаляются автоматически.
- Ролик-пример для «🎯 Монтаж как в примере» (файл или ссылка) — только для анализа стиля: он не попадает в ваш ролик и удаляется сразу после анализа; хранится лишь описание стиля (темп, паузы, вид субтитров, наезды, звук, цвет) и отпечаток файла/ссылки, чтобы не анализировать один и тот же пример повторно. Ролики по ссылке скачиваются только для этого анализа; присылайте примеры, которые вам можно использовать как образец.
- **Ссылки на чужие видео** (YouTube, TikTok, Instagram и др.): сама ссылка, её отпечаток (хэш), название и канал видео, которые сообщает платформа (для строки «Источник» в результате), и **запись вашего подтверждения прав** (ваш Telegram id, ссылка, время). Скачанное видео удаляется вместе с остальными файлами через 7 дней; запись подтверждения хранится, пока существует аккаунт (срок уточнить юристу), — она нужна, чтобы ответить на жалобу правообладателя.
- **Список заблокированных ссылок** (после жалобы правообладателя): отпечаток ссылки, номер задачи, причина и дата — хранится бессрочно, чтобы такую ссылку больше не скачивать.
- **Перевод и озвучка**: расшифровка речи, перевод по фразам и синтезированная озвучка — в папке задачи, удаляются через 7 дней. Голоса людей из видео не копируются и не клонируются.
- **Тестировщики бета-версии**: отметка, что доступ выдан автоматически или по @username, и дата.

**Зачем**
Чтобы выполнять ваши задачи, считать лимиты и кредиты, отвечать на обращения и улучшать сервис. Мы не продаём данные и не используем ваши видео для рекламы.

**Кому передаются данные (обработчики)**
- **Anthropic (Claude)** — текст задачи, расшифровка речи и описание кадров для плана монтажа, сценариев и переводов (в том числе перевода для озвучки).
- **Google (Gemini API, Cloud Text-to-Speech)** — кадры и фрагменты видео для понимания сцен и поиска моментов в играх, ролик-пример для анализа стиля (удаляется из Google сразу после ответа), текст для озвучки и перевода. На бесплатном уровне Gemini API Google может использовать запросы для улучшения своих продуктов.
- **Openverse** — поисковые запросы (ключевые слова) для открытых фото и музыки; ваши файлы туда не отправляются.
- **Telegram** — доставка сообщений и файлов.
- **YouTube, TikTok, Instagram и другие платформы** — только запрос публичной страницы видео по присланной вами ссылке (через yt-dlp, без входа в аккаунт и без cookies); ваши данные туда не передаются.
- **Google Colab** — только если вы сами загружаете туда задание для аватара.

**Ваши права**
Вы можете попросить администратора удалить ваши данные и аккаунт, отключить новости бота в ⚙️ Настройках и в любой момент перестать пользоваться ботом.

**Жалобы правообладателей**
По жалобе администратор удаляет файлы задачи (команда /takedown) и блокирует ссылку; в журнале остаются номер задачи и отпечаток ссылки.

**Безопасность**
Данные хранятся на сервере сервиса; доступ есть только у администраторов. Файлы удаляются автоматически по сроку хранения.

**Изменения**
Политика может обновляться; актуальная версия всегда доступна в боте.

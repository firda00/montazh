### Проблемы и что делать

1. **Говорящих насчитано 23** при двух реальных: 21 микрокластер по 1–6 фраз (смех, «Грок, Грок», междометия).
   На выбор «most» не повлияло. Сделать: сливать кластеры короче 10 с в ближайший по эмбеддингу; порог 0.72 проверить на
   втором многоголосом ролике.
2. **whisper-cli упал на одном куске** (995–1022 с, код 0xC0000409) — 27 с речи потеряно, пайплайн продолжил.
   Сделать: один повтор упавшего куска; если повтор падает — faster-whisper на этот кусок.
3. **Модель whisper грузится на каждый из 327 кусков** — порядка 30–40 минут впустую. Сделать: на CPU для файлов
   длиннее ~20 минут использовать сайдкар faster-whisper (одна загрузка, встроенный VAD), оставив whisper.cpp для
   коротких и смешанных по языку роликов.
4. **ingest масштабирует lanczos даже при совпадении размера и пишет CRF 18** — 32 минуты и 1.6 ГБ на статичном
   материале. Сделать: пропускать scale при scale=1; CRF 20 по умолчанию.
5. **Длительность рилсов 29–32.5 с при цели 30** — в пределах ±10%, но планировщик стабильно уходит в плюс:
   фразы Маска длинные. Можно подсказывать в промпте «лучше чуть короче цели, чем длиннее».
6. **Галлюцинации whisper** («Субтитры сделал DimaTorzok», «Редактор субтитров А.Семкин») — отфильтрованы, фильтр работает.
7. **Шортлист 38k токенов за один вызов** — для 4+ часов речи выйдет за разумный размер; сделать два прохода (по половинам)
   при > 2000 фразах.

Не проверено на этом ролике: перевод субтитров (речь и субтитры на русском), узбекская речь, шум, несколько камер.

### Сделано (2026-10-13)

- **1. Микрокластеры говорящих** — `vedit_asr.py speakers` сливает кластеры короче 10 с речи или из < 3 фраз с ближайшим
  по косинусному расстоянию центроидов, пока такие есть (`--min-cluster-seconds`, 0 — выкл.; при `--speakers N` не
  применяется). Проверка без torch: `tools/asr/.venv/Scripts/python.exe -I tools/asr/vedit_asr.py selftest` (гоняется
  и из `npm test`, если venv есть). Порог 0.72 на многоголосом ролике ещё не проверен.
- **2. Упавший кусок whisper-cli** — один повтор, затем faster-whisper на этот кусок (времена сдвигаются на начало куска,
  в `chunks.json` — `engine: "faster-whisper"`); предупреждение «failed» — только если не помогло ни то, ни другое.
- **3. Модель на каждый кусок** — `--asr auto` берёт faster-whisper и на CPU, когда файл длиннее 20 минут и сайдкар
  установлен; причина выбора — в `understand.json` (`transcriber.reason`: GPU / long file / …).
- **4. ingest** — без `scale=…:flags=lanczos`, когда размер не меняется; CRF 20 вместо 18.
- **5. Длительность рилсов** — в правилах планировщика: если фразы не дают попасть точно в цель, лучше чуть короче, чем длиннее.
- **6. Галлюцинации** — уже работало, без изменений.
- **7. Шортлист** — при > 2000 фразах два вызова по половинам индекса (окна делятся пропорционально с округлением вверх,
  результат сливается и обрезается до лимита, стоимость и токены суммируются, в `cost.json` — `calls: 2`).

Все пункты проверены тестами, не прогоном на реальном видео.

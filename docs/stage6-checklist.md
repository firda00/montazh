# Этап 6 — прогон на реальных видео: чек-лист

Запуск: `npx tsx src/batch.ts <папка с mp4> -p "3 рилса по 30 секунд, динамично, субтитры на узбекском" [--quality draft]`.
Сводка пишется в `workspace/batch-<дата>/summary.md`, по каждому ролику — `workspace/<job>/`.

Нужны 10 видео разных типов (по ТЗ): **кафе / еда**, **блогер (говорящая голова)**, **эксперт (длинный монолог)**,
**товар (обзор)**, плюс хотя бы по одному: шумный фон, узбекская речь, смешанный ru/uz, вертикальная съёмка с телефона,
видео без речи (музыка/атмосфера), 8–10 минут длиной.

## Что смотреть по каждому ролику

| Проверка | Как | Критерий (ТЗ §8) |
|---|---|---|
| Транскрипт | `transcript.json`, прослушать 3–4 фразы | Слова и язык верные; «галлюцинаций» в тишине нет |
| Сцены | `scenes.json`, `frames/shot_*.jpg` | Стыки совпадают с реальными монтажными склейками |
| План | `plan.json` → `reasoning`, `issues` | Инструкция понята (число, длительность, язык субтитров), объяснение честное |
| Границы слов | предупреждения `cut` (`cuts_word`) | Ни один клип не рубит слово; `snapped` ≤ 0.4 с |
| Синхрон субтитров | смотреть `output_*.mp4` на 2–3 страницах | Подсветка слова совпадает с речью (≤ 100 мс) |
| Говорящий в кадре (9:16) | кадры `output_*_preview.jpg`, контактный лист | Лицо не уезжает за край (сейчас центр-кроп — фиксировать как known issue) |
| Громкость | `render.json` → `loudness_after` | −14 ± 1 LUFS |
| Оформление | 3 кадра на ролик | Текст читается на фоне, нет наездов слов, титр в safe-area |
| Время/стоимость | `summary.md` | ≤ 5 мин на 10-минутное видео (ориентир), $ на план |

## Куда записывать проблемы

`docs/stage6-findings.md`: `| видео | этап | что не так | серьёзность | идея фикса |`. Группировать по этапу:
понимание (whisper/сцены), план (модель), нарезка, оформление/рендер.

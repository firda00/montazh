**Что на кадрах.** Горизонтальная HUD-композиция 16:9 стоит полосой посередине кадра 9:16 (чёрные поля сверху и
снизу ~33 %). Палитра: почти чёрный `#0A0A0A` + лайм `#D4FF00`. Шрифт — широкий гротеск капсом (Unbounded/Druk-подобный).
Хук 0–2.5 с: «ЧЕРЕЗ / **СПОРИМ?**» — огромная плашка лайм с чёрным текстом, 3D-наклон; 1.25 с: «ЧЕРЕЗ МИНУТУ ВЫ
БУДЕТЕ В **ТОТАЛЬНОМ АХУЕ**» + **круглый таймер 01:00**, который потом весь ролик тикает в правом верхнем углу
(00:59 → 00:00 на 60-й секунде — открытая петля «досмотри минуту»). Субтитры — это и есть кинетическая типографика:
белый капс 2 строки в верхней части полосы, ключевое слово в лайм-плашке (чёрный текст), отрицаемые слова
**зачёркнуты** (SORA, SEEDANCE, AFTER EFFECTS, «было: слои, ключи…» — зачёркивается целиком при «стало: написал,
подождал, забрал»). Визуальные биты под каждую фразу: окно чата с печатью промпта и вылетающими лайм-тегами
(«минуту графики», «лайм», «зерно»), код-матрица, «партитура» ключевых кадров (ромбы на дорожках), кадровая лента
«КАДР 001 → 3600» → иконка MP4, вейвформа голоса, чек-лист «персонажи ✗ / сложное 3D ✗ / титры ✓ / переходы ✓ /
графика ✓», в конце таймер 00:00 на лайм-вспышке → «НУ ЧТО, **В АХУЕ?**» с полем комментария → «Khavin Lab»
(буквы в квадратиках) + «так теперь и **работаем**».

**Gemini.** Хук — таймер-HUD + плашка; биты по 4–8 с; переходы: zoom (2.5), glitch с RGB-split (12.8), вспышка (60.5);
камера: медленный наезд по Z (4–8 с), дрейф-пан по коду; SFX: глитч-щелчок на хуке, клики клавиатуры на печати,
«блип» на ромбах, «стрекот» плёнки, вжух на смене; удар баса на 0 и на 00:00. Пайплайн: код (Claude → Remotion/
Three.js-подобный JS на экране) + ИИ-голос; ~7 «перебивок» на 10 с.

**Взять:** таймер-обещание как открытая петля; зачёркивание как приём «не X» без слов «не X, а Y»; маркер-плашка
ключевого слова; каждый бит — свой UI-объект, связанный со словом.

## (d) Правила вставок (B-roll / скрины / лого / PiP)

1. **Триггер — названная сущность или число в речи.** Вставка начинается на начале слова (0…−0.2 с, #14, #15),
   не раньше — зритель должен сначала услышать.
2. **Тип вставки по типу сущности:**
   - событие/действие/объект («презентовал автомобиль», «взлетает») → **полноэкранная перебивка-видео/фото** 3–4 с,
     субтитры остаются поверх на прежнем месте (#14);
   - человек, о котором говорят (не спикер) → **PiP-фото с вырезанным фоном** ≈25 % ширины на груди над субтитрами,
     2–3 с, fade (#14);
   - компания/продукт → **запись прокрутки её сайта** (мобильная версия) в карточке 80 % ширины 4–6 с (#15), затем
     **логотип-карточка** + чипы фактов;
   - число / деньги / дата → **чип-пилюля** «год + глагол + сумма» (белая, чёрный текст), копятся стопкой, финальный
     контрастный (чёрный) — панчлайн; держатся до конца сюжетного блока и уходят вместе на склейке (#15);
   - эмоция/ирония («инвесторы получили ноль») → мем/реакция (#15, #04) — **у нас только лицензионно-чистые
     аналоги** (см. гэп-лист).
3. **Плотность:** вставки сосредоточены в хуке и сюжетной части (первые 25–40 % ролика); в «выводах/советах» —
   чистая голова (#15), либо равномерно ≈1 на 8–10 с (#14). Доля времени под перебивками 25–35 %.
4. **Длина:** полноэкранная 3–4 с (не больше фразы), PiP 2–3 с, сайт 4–6 с, чипы — до 13 с как накопительный слой.
5. **Голова не уходит надолго:** между двумя полноэкранными вставками ≥ 1 фраза головы (≥ 1.5 с).
6. **Субтитры поверх вставок** — тем же стилем и местом; вставки-карточки ставятся над головой/над субтитрами, лицо не
   закрывают (PiP — на груди, сайт/мем — выше подбородка… у #15 сайт закрывает голову целиком — допустимо на 5 с).
